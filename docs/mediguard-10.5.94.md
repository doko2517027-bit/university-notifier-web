# メディガ 10.5.94

## 今回の変更

- キャラクターの目・表情・服・手足などの立体造形を更新。戦闘時の大きさを縮小し、前方で重なる敵を半透明化。
- メニューと操作ボタンを丸みのあるゲーム専用UIへ変更。CareMateへ戻る操作はゲームのメニューにのみ表示。
- 3Dカプセルが開くガチャ演出。高レア確定・昇格演出、スキップ、確定済み結果の表示。
- ブラウザ内で電子音を鳴らす方式を廃止。オリジナルの8音声ファイルを追加。管理画面から画面別BGM・操作別効果音、計33枠を編集できる。
- MP3/M4A/WAV/AAC/OGG、1ファイル25MBまで。既存Cloudinaryへの保存、試聴、音量、再生オンオフ、標準音への復帰を用意。
- 最大10枠の協力ルーム。6桁コード、準備完了、ホスト開始、読み込み待ち、同じマップでの戦闘同期、復活・観戦・結果保存。

## 保存と認可

- `mediguardGameConfig/settings.audio`: 管理者だけがサーバー経由で設定。音声URLはCareMateのCloudinaryアカウントに限定。
- `mediguardCoopRooms`, `mediguardCoopCodes`, `mediguardCoopJoinLimits`: サーバーのみ読み書き。
- Realtime Database `mediguardCoop/{roomId}`: 限定テスターかつ参加所有者だけ読み取り可能。ブラウザからの書き込みは禁止。
- 既存 `mediguardPlayers/{studentNumber}/operations/coop_{roomId}`: 同じ試合の報酬を一度だけ確定。
- 協力戦はサーバーが移動・障害物・攻撃・スキル・敵・残機・勝敗を計算する。クライアントのダメージ値・勝敗申告は使用しない。
- 既存の累計学習ポイント、他学生のデータは変更しない。

## 確認

- PC、スマホ縦390×844・横844×390のメニュー、戦闘、ガチャ、音声管理をブラウザで確認。
- サーバーの2参加者ルーム作成～開始・同期と10参加者の状態初期化、未許可アクセス拒否、途中切断、全員死亡、偽の勝利、報酬重複防止を自動テストで確認。
- Cloudinaryへ4.3KBの標準クリック音を実際にアップロードし、そのURLを共通ボタンの標準音として使用。

## 限定テスト上の注意

- 本番ログイン済みの2端末・10人同時実機プレイは未確認。現在のブラウザにはCareMateのログイン情報がないため、ユーザーのパスワードを取得・代行入力していない。
- 2510044だけのテスト。同アカウントの別端末・別タブからルームへ参加できる。同アカウントの報酬は試合ごとに一度のみ。
- 協力戦は約350ms間隔のサーバー更新＋端末側の移動予測。通信環境によって遅延・位置補正がある。商用アクションゲームと同等の通信品質を保証するものではない。
- 新しい有料契約・常時起動サーバーは追加していない。既存Firebase/Cloudinaryの使用量は増えるため、利用量による従量課金まで無料保証するものではない。
- 標準音楽は自作の仮音源。実際の楽器録音ではなく、好みに合うMP3等へ差し替え可能。既存ゲームの素材・音楽は使用していない。
