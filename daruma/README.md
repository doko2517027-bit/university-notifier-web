# だるまさんがころんだ — 2510044限定CPU試験版

CareMateの「リクエスト」タブを、学籍番号2510044のログイン済みアカウントだけ「だるま」に切り替えます。他の学生のタブとデータは変更しません。直接URLで開いた場合もFirebase AuthのUID・トークン内の学籍番号・Firestore上の本人情報を確認し、合致しなければゲームを読み込みません。

## 実装済み

- 独立したThree.js 3Dステージ、PC/スマホ向けUI、FPS/TPS視点
- 4〜10人のCPU対戦、鬼/逃走者/ランダムの役割選択
- 鬼の任意の振り向き、5秒上限、早めの伏せ、3残機
- 指摘した瞬間の実移動速度での正誤判定（過去に動いた事実だけでは脱落しない）
- 鬼の実際の視点からの障害物遮蔽判定、見えている部位のクリック選択
- 滑る床・動く床を含む移動判定、ダッシュ、障害物との衝突
- 鬼への近距離タッチ、CPUの鬼/逃走者、勝敗・次ラウンド・鬼交代
- 端末内の視点・画質・感度設定保存

## 未実装・制約

- フレンド対戦・ルーム・リアルタイム同期・サーバー側の勝敗判定は未実装で、UI上も「準備中」と明示しています。静的なGitHub Pagesでは低遅延の権威サーバーを運用できません。また現行の2510044限定では別の学生アカウントを対戦相手として実地検証できません。オンライン戦は信頼できるサーバーと、追加の試験アカウントの公開許可が必要です。
- CPU戦の結果はクラウド保存しません。CareMateのポイントや学習データも変更しません。
- GitHub Pagesの静的ファイル自体は公開配信されます。ログイン判定はゲーム起動の制限であり、HTML/JavaScriptファイルのダウンロードまで遮断する方式ではありません。秘密や個人データはこのディレクトリに含めないでください。
- 仮の3Dキャラクターとステージです。正式素材ではありません。

## 操作

PC：WASDで移動、Shiftでダッシュ、右ドラッグで視点操作、VでFPS/TPS、鬼はEで振り向き・Fで伏せる、左クリックで指摘/タッチ、Escで一時停止。

スマホ：左側の仮想スティックで移動、右側スワイプで視点操作。役割に応じて表示されるボタンでダッシュ、振り向き、伏せ、タッチを操作します。

## 開発・検証

`npm test` で描画に依存しないルールを検証します。ローカルで表示するにはリポジトリ直下からHTTPサーバーを起動し、`/daruma/` を開いてください。ログインしていない環境ではアクセス拒否画面になります。
