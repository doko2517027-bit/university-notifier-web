# Throb（Throw Obje）仕様

身近な物を投げ合う3D対戦アクション。PC・タブレットと、横画面のiPhone/Androidを想定する。

## 現在遊べる試作範囲（Phase 0〜5）

タイトル → 初回チュートリアル → メインメニュー → 対戦設定 → CPU戦 → 結果 → 再戦またはメニュー。教室ステージで、パソコン・ナイフ・ベッドを切り替えて投げられる。難易度は簡単・普通・難しい。生き残り勝負と撃破数勝負を選べる。1対1、5分、HP100、3機。死亡後10秒で復活し、3秒無敵。引き分け時はサドンデスに進む。障害物・ジャンプ台・絆創膏を設置。

試合のEXPでレベルが上がり、獲得した能力ポイントをHP・攻撃・防御・移動・腕力へ振り分けられる。メニューから3つの武器、頭・胴防具、2つのスキルを選択できる。応急手当、防壁、クイックステップはCPU戦で使用可能。試合で得た練習パーツで武器を強化でき、倉庫で初期所持品を確認できる。装備、育成、試合数はこのブラウザ内に保存する。

## Phase 6の限定公開範囲

CareMateの既存Firebase認証のUID・学籍番号クレーム・学生プロフィールを照合し、`2510044` のみ試作データのクラウド同期を試みる。記録が競合した場合は端末かクラウドのどちらを使うか選択する。公式学習ポイントは表示のみ。本人の実機での同期確認は引き続き必要。

## Phase 7の実装中範囲（未公開）

2510044だけに独立したテスト用残高を最初に500pt付与する。4種類のガチャはCloud Functionsで抽選・残高減算・個別アイテム保存を一括処理する。同じ受付番号の再送は保存済み結果を返し、二重消費しない。10連にはSR以上1件の保証を設ける。獲得品は専用倉庫で確認できるが、3Dモデル・装備・対戦能力とはまだ連動しない。正式な学習ポイントの引き継ぎ・加算も未実装。

## 設計上の境界

試作は `throwbattle/` 単独で起動できる。本人確認できない環境では端末内に保存する。ショップ、オンライン等は「開発中」と表示する。試合報酬はクライアント側で算出した試作値であり、公式学習ポイントやオンライン報酬ではない。Phase 6のクラウド記録も公式の価値を持つデータとして扱わない。現在の `totalRanking` はクライアントが書き換え可能なため、これをサーバーで検証できるようになるまでガチャの正式通貨には使わない。
