# Throb（Throw Obje）仕様

身近な物を投げ合う3D対戦アクション。PC・タブレットと、横画面のiPhone/Androidを想定する。

## 現在遊べる試作範囲（Phase 0〜5）

タイトル → 初回チュートリアル → メインメニュー → 対戦設定 → CPU戦 → 結果 → 再戦またはメニュー。教室ステージで、パソコン・ナイフ・ベッドを切り替えて投げられる。難易度は簡単・普通・難しい。生き残り勝負と撃破数勝負を選べる。1対1、5分、HP100、3機。死亡後10秒で復活し、3秒無敵。引き分け時はサドンデスに進む。障害物・ジャンプ台・絆創膏を設置。

試合のEXPでレベルが上がり、獲得した能力ポイントをHP・攻撃・防御・移動・腕力へ振り分けられる。メニューから3つの武器、頭・胴防具、2つのスキルを選択できる。応急手当、防壁、クイックステップはCPU戦で使用可能。試合で得た練習パーツで武器を強化でき、倉庫で初期所持品を確認できる。装備、育成、試合数はこのブラウザ内に保存する。

## 設計上の境界

試作は `throwbattle/` 単独で起動し、CareMateの認証・ポイント・Firebaseには接続しない。育成・装備はブラウザ内に保存するが、別端末への同期はない。メニューのガチャ、ショップ、オンライン等は「開発中」と表示する。試合報酬はローカル試作値であり、不正防止が必要なオンライン報酬ではない。
