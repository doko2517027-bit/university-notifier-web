# Throb（Throw Obje）仕様

身近な物を投げ合う3D対戦アクション。PC・タブレットと、横画面のiPhone/Androidを想定する。

## 現在遊べる試作範囲（Phase 0〜4）

タイトル → 初回チュートリアル → メインメニュー → 対戦設定 → CPU戦 → 結果 → 再戦またはメニュー。教室ステージで、パソコン・ナイフ・ベッドを切り替えて投げられる。難易度は簡単・普通・難しい。生き残り勝負と撃破数勝負を選べる。1対1、5分、HP100、3機。死亡後10秒で復活し、3秒無敵。引き分け時はサドンデスに進む。障害物・ジャンプ台・絆創膏を設置。

## 設計上の境界

試作は `throwbattle/` 単独で起動し、CareMateの認証・ポイント・Firebaseには接続しない。CPUの勝敗や結果はブラウザ内の1試合のみで、保存されない。メニューのガチャ、ショップ、育成、オンライン等は「開発中」と表示する。

キャラ育成、能力振り分け、3武器・2防具・2スキル、4種のガチャ、フレンド、2〜8人のオンライン、ランク、通報、ゲーム専用管理、CareMate連携とタブ統合はPhase 5以降の対象。オンラインの勝敗・報酬は将来サーバーで確定する。課金・有償ポイントも未実装。
