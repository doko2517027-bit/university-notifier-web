# キャラクター制作

現段階は「ルーキー」1種の仮モデル。将来の人・猿・犬などは、各キャラのID、能力値、モデルパスを `src/data/config.js` の `CHARACTERS` に追加する。能力値はモデルに含めない。モデル変更でHPや攻撃判定が変わらない構造にする。

- 推奨形式：GLB。足元を原点、正面を `-Z`。身長は約2.4単位。
- 骨格・体型は自由。ただし当たり判定は現在共通の円柱近似（半径約0.56、高さ約2.55）。異なる体型の本調整は後続Phaseで行う。
- アニメーション名：`idle`、`walk`、`dash`、`jump`、`land`、`throw`、`hit`、`defeat`。大文字小文字は自動で小文字に合わせる。
- 育成情報、服・髪型・顔・色・アクセサリーは後続Phaseでモデルと別のデータに保存する。

仮モデルはコード生成なので素材未制作でもCPU戦を続けられる。制作物を公開する際は、素材の利用権を確認する。
