# ハルト44コマの品質点検（正式完成判定ではない）

## 結論

現在の44コマは全て表示・再生できますが、**正式品質の全動作完成とは判定しません**。特に走行の足が交互になっていません。元画像の無理な変形や、ほぼ同じ絵の複製による水増しは行いませんでした。

設計図 `docs/reference/haruto_design.png` と既存の待機4コマを基準に、全11動作・各4コマを一覧、拡大、確認画面の再生で見ました。自動検査 `node tools/audit_haruto_frames.mjs` は44枚すべてで、512×512 RGBA、画面端に有色画素なし、足元の最下端が基準488pxから3px以内でした。これは画像形式・配置の合格であり、動きやデザインの合格を意味しません。

## 動作別の目視結果

| 動作 | 現状（4コマ） | 正式化に必要な改善 |
|---|---|---|
| idle | 設計図由来の原画を分離した既存素材。髪・目・衣装は一貫。足元も安定。 | 既存を維持。全装備アンカーを正式装備が来た段階で確認。 |
| run | 01～04で前に出る脚がほぼ同じ。02は少し浮くが、交互の接地周期になっていない。 | **同一視点・同一衣装で左右脚が交互になる8コマを一連の周期として新規制作**。接地2回、蹴り出し2回、すれ違い2回、飛行2回を含める。 |
| jump | しゃがみ→踏み切り→空中の姿勢は読める。02から03の腕・脚の変化が大きい。 | 上昇中の中間1～2コマ。頂点での姿勢を落下開始へ自然につなぐ。 |
| fall | 広げた腕、下がる脚、着地準備の違いは読める。ジャンプ最終姿勢から表情と手の開きが急変。 | 頂点直後の中間1コマ、着地直前の中間1コマを同じ顔・服装で追加。 |

| respawn | 起き上がりの段階が読める。 | 立ち上がる中間と着地の1～2コマ、無敵表示との同期。 |
| victory | 跳ねる・笑う・拳を上げる表現。従来は4→1のループで急に姿勢が戻った。 | **今回、最終コマを保持するよう修正済み**。さらに跳躍・着地の中間と自然な終端を制作。 |

## 次に制作してほしい画像素材（優先順）

1. **run：8コマを連続制作**。右向き横視点、透明PNG、512×512、足元488px。近い脚が前の接地→体重移動→蹴り出し→空中→遠い脚が前の接地→体重移動→蹴り出し→空中。腕は脚と逆位相。前後の脚・靴を明確に描き分ける。最重要。参照は正式設計図、`idle_01.png`、現行`run_01.png`。一枚ずつ別生成すると体型が変わるため、同じキャラクターシート／3D元モデルからのレンダリングなど、形状を固定した制作が望ましい。ただしゲームへは2D PNGで納品し、こちらでは3Dモデルを作らない。
2. **jump：中間2コマ**。`jump_02.png`の踏み切りから`jump_03.png`の空中姿勢へ、腕と膝の移動が半分ずつ進む姿勢。既存4枚と同じ視点・衣装。
3. **fall：中間2コマ**。`jump_04.png`の膝を抱えた頂点から`fall_01.png`の開いた腕への移行、および`fall_03.png`から`fall_04.png`の着地姿勢への移行。
4. **attack：6コマの連続セット**。黒・赤のノートパソコンを後ろ手で握る、引く、加速、**放す瞬間（ゲームの投擲フレーム）**、追従、回復。PCは別画像を重ねる設計を維持し、手指は武器を握っている形を描く。参照は正式設計図、`attack_01.png`～`attack_04.png`、`assets/weapons/haruto_laptop.png`。
5. その後にskill 8コマ、dodge 6コマ、death 6コマ、respawn 6コマ、victory 8コマを一体の同じハルトとして制作。hitは現4コマを詳細照合してから追加の要否を決める。

全素材で赤髪の毛束、赤茶の目、パーカーのファスナーと赤い裾、黒い短パンと赤ストラップ、指なし手袋、靴側面の赤い丸印を統一してください。四角切り抜き・黒背景合成・影・テキストは不可。資料画像の小さなポーズをそのままゲーム用に切り抜くこともしません。

## 画像生成の試行

組み込み済みの画像生成機能を使用し、透明背景で、次の指示と参考画像を与えました。

- 「正式設計図＋既存走行01を参照。脚を逆にし、遠い脚を前で接地、腕を逆位相にした4ポーズの後半周期」：脚が逆転せず不採用。
- 「走行01の顔・服・比率を固定し、前後の脚と腕だけ交換した単一ポーズ」：脚が逆転せず不採用。
- 「正式設計図のみを参照し、前後脚の役割を明確にした反対接地ポーズ」：同じ脚主体・衣装細部にも差が出て不採用。
- 「jump_04とfall_01の中間となる頂点ポーズ」：落下01に近く、追加する意味が乏しいため不採用。
- 「attack_02とattack_03の間で、投擲腕の拳を胸元に置く加速姿勢」：腕がすでにほぼ放出姿勢となり、既存03との差が不足するため不採用。

画像生成の成功を装って低品質素材を登録することはせず、候補はプロジェクト外の生成画像フォルダに留めました。既存44コマや正式デザイン資料は上書きしていません。
