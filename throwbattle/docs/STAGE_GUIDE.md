# ステージ制作

最初の教室は幅34、奥行28ゲーム単位。`src/data/config.js` の `STAGES.classroom` にプレイヤー出現地点、遮蔽物の位置とサイズ、ジャンプ台、絆創膏の出現地点がある。`src/stages/classroom.js` はこのデータを使って当たり判定する。

`ASSETS.stages.classroom` にGLBのパスを指定すると、仮の床・壁・机などの表示をGLBに替える。衝突用データはそのまま残る。GLBの床は `Y=0`、中心は原点に合わせる。見た目の壁や机の位置を変えたら `cover` などの座標も合わせる。モデルの読み込み失敗時は教室の仮表示に戻る。

屋外や病院などは `STAGES` に別IDを増やす設計。現段階で実際に選べるのは教室のみ。CPUの移動は簡易的な遮蔽物回避で、経路探索は後続Phaseの改善対象。
