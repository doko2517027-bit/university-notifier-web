# ハルト：正式デザイン基準

この文書と [設計図](reference/haruto_design.png) は、ThrobのキャラクターID `haruto` の正式な外見基準です。設計図は **1人のキャラクター** の複数方向・表情・参考ポーズをまとめたものです。下部の小さなポーズ例は完成済みのスプライトシートではありません。ゲーム内のアニメーションに切り抜いて流用しないでください。

- 名前：ハルト。人型、約3頭身。明るく元気で活発。物を投げる戦闘スタイル。
- 外見の固定要素：ボリュームのある赤いツンツン髪、大きな赤茶色の目、丸い顔、白・赤・黒のパーカー、黒いハーフパンツ、黒いフィンガーレスグローブ、赤・白・黒の大きなスニーカー、丸く滑らかなシルエット。
- 設計図の正面・左右側面・背面・斜め45度、表情差分、配色を以後の制作で参照します。Work側で再デザインしません。
- 画像の例示装備は正式装備ではありません。投擲武器として黒・赤のノートパソコン画像を独立したPNGで導入しました。ヘルメットやバックパックの正式画像は未確定です。
- `assets/characters/haruto/character.json` の数値はテスト用の仮設定です。待機4コマは提供原画から制作した素材、その他の10動作×4コマは設計図と待機画像を参照して制作した**アニメーション初稿**です。各動作の推奨枚数や最終的な見た目の確認は未完了です。
