# 動作確認手順

1. リポジトリの親ディレクトリで静的HTTPサーバーを起動し、`/throwbattle/` を開く。
2. 「タップしてスタート」→初回遊び方→メニュー→対戦設定→CPU戦へ進む。
3. PCでWASD移動、マウス視点、左クリック投擲、1〜3武器、Spaceジャンプ、Shiftダッシュ、V視点切替、Esc一時停止を確認する。
4. 教室の机・壁で移動と投射物が止まること、ジャンプ台、絆創膏、CPUの攻撃、HP・残機・復活・無敵を確認する。
5. 試合終了または一時停止メニューから退出し、結果表示、再戦、メニュー復帰を確認する。画面遷移後に前のCanvasが残らないことも見る。退出ではEXPを獲得しない。
6. スマホ実機の横画面で左スティック、右スワイプ、投擲、ダッシュ、ジャンプ、3武器を同時に操作する。縦画面では回転案内を確認する。
7. メニューの「キャラクター」「武器」「倉庫」を開く。武器の順番・防具・2つのスキルを変更し、CPU戦で出撃時HP、武器順、スキル効果とクールタイムを確認する。PCではQ/Eでスキルを使う。試合で練習パーツを得たら「武器を強化」でLvと威力が上がり、パーツが減ることを確認する。
8. 試合の勝敗後にEXPと試合数を確認し、ページを再読み込みしても記録と装備が維持されることを確認する。レベルアップ後に能力ポイントを割り振る。
9. Phase 6のクラウド同期は、Firestoreルールを公開するまでは「この端末に保存」または同期不可と表示される。公開後に同じCareMateドメインで本人 `2510044` としてログインし、クラウド保存、別端末読み込み、競合時の手動選択、他学生のアクセス拒否を確認する。ローカルプレビューだけでは本番ログイン・別端末同期を確認できない。

自動テストは `throwbattle/` で `npm test`。戦闘、ローカル保存に加え、本人照合、クラウド記録の形式、初回移行、競合・上書き防止を疑似アダプターで確認する。実機のタッチ・Safari/Chrome差、長時間対戦、本番Firebase認証・権限ルール・別端末同期は手動確認が必要。オンライン対戦、公式学習ポイントの加算・消費、CareMateタブ連携は未実装。
