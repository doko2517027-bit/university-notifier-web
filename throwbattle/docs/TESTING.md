# 動作確認手順

1. リポジトリの親ディレクトリで静的HTTPサーバーを起動し、`/throwbattle/` を開く。
2. 「タップしてスタート」→初回遊び方→メニュー→対戦設定→CPU戦へ進む。
3. PCでWASD移動、マウス視点、左クリック投擲、1〜3武器、Spaceジャンプ、Shiftダッシュ、V視点切替、Esc一時停止を確認する。
4. 教室の机・壁で移動と投射物が止まること、ジャンプ台、絆創膏、CPUの攻撃、HP・残機・復活・無敵を確認する。
5. 試合終了または一時停止メニューから退出し、結果表示、再戦、メニュー復帰を確認する。画面遷移後に前のCanvasが残らないことも見る。
6. スマホ実機の横画面で左スティック、右スワイプ、投擲、ダッシュ、ジャンプ、3武器を同時に操作する。縦画面では回転案内を確認する。

自動テストは `throwbattle/` で `npm test`。`BattleSession` のHP、残機、10秒復活、3秒無敵、勝敗、時間切れを確認する。実機のタッチ・Safari/Chrome差と長時間対戦は手動確認が必要。オンライン対戦、ポイント保存、CareMateタブ連携は未実装なので現時点のテスト対象外。
