# 動作確認手順

1. リポジトリの親ディレクトリで静的HTTPサーバーを起動し、`/throwbattle/` を開く。
2. 「タップしてスタート」→初回遊び方→メニュー→対戦設定→CPU戦へ進む。
3. PCでWASD移動、マウス視点、左クリック投擲、1〜3武器、Spaceジャンプ、Shiftダッシュ、V視点切替、Esc一時停止を確認する。
4. 教室の机・壁で移動と投射物が止まること、ジャンプ台、絆創膏、CPUの攻撃、HP・残機・復活・無敵を確認する。
5. 試合終了または一時停止メニューから退出し、結果表示、再戦、メニュー復帰を確認する。画面遷移後に前のCanvasが残らないことも見る。退出ではEXPを獲得しない。
6. スマホ実機の横画面で左スティック、右スワイプ、投擲、ダッシュ、ジャンプ、3武器を同時に操作する。縦画面では回転案内を確認する。
7. メニューの「キャラクター」「武器」「倉庫」を開く。武器の順番・防具・2つのスキルを変更し、CPU戦で出撃時HP、武器順、スキル効果とクールタイムを確認する。PCではQ/Eでスキルを使う。試合で練習パーツを得たら「武器を強化」でLvと威力が上がり、パーツが減ることを確認する。
8. 試合の勝敗後にEXPと試合数を確認し、ページを再読み込みしても記録と装備が維持されることを確認する。レベルアップ後に能力ポイントを割り振る。
9. Phase 6のクラウド同期は、同じCareMateドメインで本人 `2510044` としてログインし、クラウド保存、別端末読み込み、競合時の手動選択、他学生のアクセス拒否を確認する。ローカルプレビューだけでは本番ログイン・別端末同期を確認できない。

自動テストは `throwbattle/` で `npm test`。戦闘、ローカル保存に加え、本人照合、クラウド記録の形式、初回移行、競合・上書き防止を疑似アダプターで確認する。実機のタッチ・Safari/Chrome差、長時間対戦、本番Firebase認証・権限ルール・別端末同期は手動確認が必要。オンライン対戦は本人限定の試作で、公式学習ポイントの加算・消費は未実装。

# オンライン待機室の限定テスト

`2510044` でCareMateにログインし、Throb → 対戦する → オンライン待機室を試す。無料サーバーが休止中なら初回接続に1分程度かかる。ルームを作ると6桁の番号、ホスト、準備状態が表示される。本人による接続・ルーム作成は実機確認済み。次に別端末でも同じアカウントで開き、ルーム番号を入力して参加、両端末で2人表示・準備状態・退出時のホスト移譲を確認する。2510044だけ最大3台まで同時参加でき、端末は別参加枠として表示される。この特例は通信テスト専用で、他学生に拡大しない。ログアウト済み・他学生にはゲーム本体が開かない。

両端末で準備完了を押し、ホスト側で「対戦を始める」を押す。3秒のカウントダウン後、両端末で自分と相手が見えること、WASD/左スティック移動、視点、投擲、HP・残機、勝敗と結果画面を確認する。2端末の対戦と操作感の改善は実機確認済み。短いジャンプ入力が失われないことも確認する。明示的な「退出」は即座に試合を離れ、一時的な通信切断は最大60秒間復帰を試みる。ここで表示する試合結果は2510044限定の通信試作であり、公式EXP・学習ポイント・戦績には加算しない。一般学生どうしの対戦、フレンド招待、公式報酬は未実装。CPU戦のローカル試作結果をオンライン戦績として使わない。Renderの無料枠を超えた場合、カード未登録ワークスペース内のサービスが止まる可能性がある。

通信復帰の確認：試合中に片方の端末だけ機内モードを数秒入れて戻す。切断中は「通信を復旧中」と表示され操作が止まり、60秒以内なら同じルーム番号・参加枠・試合へ戻ることを確認する。もう片方の画面では相手が「再接続待ち」になり、勝手に新しい参加枠が増えないことを確認する。60秒を超える切断は試合から退出扱いとなる。サーバー再起動による試合消失は現段階では復旧対象外。

3台の表示確認：3台を同じルームへ入れて対戦を開始する。各画面右上にほかの2台の体力・残機・状態がそれぞれ表示される。片方の通信を一時停止すると「再接続待ち」、復帰すると「対戦中」に戻る。1台が明示的に退出しても残る2台の対戦は続く。決着後の結果画面には全員の順位・撃破数・残機が表示され、退出者が勝者にならないことを確認する。画面の短い横向き表示で、相手一覧が下の操作ボタンを隠さないことも確認する。
