# ハルト・パーツ分割式走行アニメーションの検証

## 判定

**既存の1枚絵だけを分割する方法では、正式品質の走行には到達しません。**

独立した比較画面 `tools/haruto_rig_preview.html` を作り、現行 `run_01.png`〜`run_04.png` と、`idle_01.png` を8部位に分けて動かす8姿勢の試作を並べました。どちらもゲーム用設定に接続していません。ハルトの44コマ、`character.json`、ゲームロジック、当たり判定は変更していません。

## 試した方法と結果

| 観点 | 従来の4コマ | 今回の試作 |
|---|---|---|
| 顔・髪・衣装の一貫性 | 大きな変化はない | 同じ `idle_01.png` の画素を使うため変化しない |
| 腕と脚の位相 | ほぼ同じ前脚のまま | 左右を逆位相で回転させられるが、見た目は自然な交互走行に届かない |
| 接地 | 交互の接地周期がない | 靴を脚から分離して低い側を基準線に合わせたが、半周期で両足が重なり、滑る |
| 関節 | 1枚絵としては破綻しない | 肩・股関節・足首で元画像の隠れた面がなく、切れ目や欠けが見える |
| 膝・靴 | コマごとの絵に依存 | 膝を曲げられず、靴の向き・接地面を自然に維持できない |

ブラウザで再生・一時停止・コマ送りを確認しました。半周期に相当する姿勢5/8では、前後の脚を反転させようとすると靴が体の真下付近で重なります。元画像は脚がそれぞれ1つのポーズに描かれ、反対方向へ伸びる太もも・すねの裏面がないためです。足を大きく水平移動させると今度は股関節から離れます。膝と足首を独立させても、その裏側・つなぎ目を単一の完成絵から復元することはできません。

## 技術的な見通し

**パーツ分割方式自体は有望ですが、「完成した1枚絵を切る」だけでは不足します。** 描画側で関節、前後の重なり、8〜12姿勢の走行周期を制御できます。顔や衣装の一貫性も保てます。ただし、自然に曲がる関節と左右の脚の交互接地には、隠れていた面を描いた専用パーツが必要です。

正式素材がそろうまでは、現行スプライトを維持します。パーツ式を採用する場合も、既存の位置・HP・攻撃判定を独立させたまま描画部分だけを差し替える設計が可能です。

## 追加で必要な画像素材

正式デザイン `docs/reference/haruto_design.png` と `assets/characters/haruto/animations/idle_01.png` に合わせ、**右向き・透明背景PNG**で以下を制作してください。各パーツを1つずつ独立させ、切断部には回転しても隙間が出ない余裕を持たせます。

1. 頭＋髪＋顔：首の後ろ側まで見える一体の画像。正面寄りの顔は不要で、現行の右向き横視点と同じ比率。
2. 胴体＋パーカー：腕・脚を外した前後の面、肩・股関節の内側、フードの背面。ファスナーや胸・裾の赤黒模様を設計図どおり固定。
3. 左右それぞれの上腕・前腕・指なしグローブ：遠近で見える表裏の違いを含む。肘を曲げても袖と手袋の隙間が出ない接続面。
4. 左右それぞれの太もも・すね：短パン裾の内側、膝の前後、足首の接続面。遠い脚も完全な形で納品。
5. 左右それぞれのスニーカー：甲・側面・靴底が途切れない画像。足首で角度を変えても靴が変形しない分離形状。
6. 肩・肘・股関節・膝・足首用の小さな継ぎ目カバー、または各部位の重なりでカバーできる余白。

各画像には足元の原点だけでなく、接続する**ピボット座標**（例：肩、肘、手首、股関節、膝、足首）と、手前・背後の描画順を添えてください。全体の完成姿を512×512キャンバスに置いたときの足元は既存規格どおり `(256, 488)`。素材は同一の設計原画またはレイヤー分けされた原稿から作り、別々の生成で顔や服の模様を変えないでください。PSDなどのレイヤー原稿があるなら、そこから書き出した透過PNGが最も確実です。

最初の受け入れ判定は、**8〜12姿勢を1周再生して左右の靴が交互に接地し、膝が曲がり、継ぎ目・足滑りが見えないこと**です。これを満たしてからゲームに採用します。
