# ハルト実装・品質報告

## 判定

**B：機能完成・素材は初稿（正式品質未完成）**。ハルトを選んでCPU戦を最後まで遊べますが、待機以外の動作は各4コマの初稿です。走行・攻撃・死亡・勝利などは、推奨枚数と動きの自然さを引き続き磨く必要があります。正式な防具画像もありません。これらを「正式完成」とは扱いません。

## 実装したもの

- 既存の設計図と待機4コマを変更せず維持。
- 走行、ジャンプ、落下、通常攻撃、スキル、回避、被弾、死亡、リスポーン、勝利を各4コマの透過PNGで追加。待機と合わせて11動作・44コマ。
- 設計図と既存の待機画像を参照して動作ごとの4ポーズ原画を生成。輪郭を検出して各人物を分離し、足元を揃えた512×512の透過画像に配置。設計図の小さな参考ポーズを単に切り抜いたものではありません。
- 独立したノートパソコン画像（256×256透過PNG）と投擲物の表示。攻撃アニメーションの3コマ目で発射。
- Power Throwは3.2秒間、攻撃力1.4倍・弾速1.18倍。8秒のクールダウン。効果と残り時間を対戦画面に表示。
- 回避、被弾、死亡、復活、勝利の状態に応じたアニメーションを対戦処理へ接続。HP・ストック・10秒後復活・3秒の無敵は既存ルールを維持。
- 装備は画像・アンカー・前後レイヤーを分離した既存の仕組みを維持し、開発用ヘルメットを着脱可能にした。正式な頭部・胴体・バックパック画像は未制作。
- 全キャラクター共通のアニメーション確認画面 `tools/animation_preview.html` を追加。再生・停止・コマ送り・FPS変更・背景変更・足元線・当たり判定・装備アンカーを確認できる。

## 動作確認

- `npm test`：19件すべて成功。画像44枚のサイズ・アルファチャンネル、武器画像、攻撃3コマ目の投擲、時限スキル、死亡・復活・勝利の状態を確認。
- ローカルブラウザで確認画面を開き、走行再生と攻撃コマ送り、足元線・当たり判定・装備アンカーを確認。攻撃時の手元位置を調整。
- 実際のローカルCPU戦で、ハルトを選択し、Power Throwとノートパソコン投擲を使用。125ダメージを与えて勝利し、結果画面まで確認。
- スマホ実機のマルチタッチ、全44コマの端末別見え方、全ての装備アンカーの精密確認は未実施。PCブラウザでの検証をもってスマホ実機検証済みとはしない。

## 残る品質課題

- 各動作が4コマのため、特に走行・攻撃・死亡・勝利は推奨枚数まで増やし、中間姿勢と接地の自然さを再確認する。
- 画像生成による各動作の細部（髪束、靴、パーカー装飾、手袋、表情）を設計図と1コマずつ照合し、必要な修正を行う。
- 動作ごとの正式な頭部・胴体・背中装備画像と、全フレームのアンカー調整。
- 効果音や本番用の攻撃・命中エフェクトは今回の正式素材としては制作していない。
- CareMate本体・AMAMON・Firebase・公開環境は変更していない。Throbは引き続き独立したローカル試作。

正式画像の差し替え先と制作規格は [SPRITE_ASSET_SPEC.md](SPRITE_ASSET_SPEC.md) を参照してください。

次工程の全44コマ品質点検と追加素材の指定は [HARUTO_QUALITY_REVIEW.md](HARUTO_QUALITY_REVIEW.md) に記録しています。勝利アニメーションは、初稿の4コマ目から1コマ目へ急に戻らず、最終姿勢を保持するよう調整しました。
