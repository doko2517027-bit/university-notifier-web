# 武器制作

武器データは `src/data/config.js` の `WEAPONS` にある。`id` は保存や参照に使う固定識別子。`model` は `ASSETS.weapons` のGLBパス。攻撃力 `damage`、弾速 `projectileSpeed`、連射間隔 `cooldown`、重さ `weight`、射程 `range` を見た目から独立して設定する。

最初の仮武器はパソコン・ナイフ・ベッド。新しい武器は同じ項目を持つデータを追加すれば、選択UIと投擲に反映する。現段階の当たり判定は投射物の中心点で処理する。爆発・貫通・毒・回復・吹き飛ばしの実処理や強化は後続Phase。

武器GLBの原点を中心、前方を `-Z` として制作する。投射物として使われるため、見た目の大きさは `size` と照らして確認する。読み込みに失敗すると各武器の仮モデルを使用する。
