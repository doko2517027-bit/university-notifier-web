# ハルトの正式アニメーション画像の追加先

このフォルダには、背景透過PNGを `idle_01.png`、`run_01.png` などの名前で配置します。待機4コマ `idle_01.png`〜`idle_04.png` は提供された待機アニメーション原画から、輪郭に沿ってノイズを除去し配置しました。その他の10動作には、正式設計図と待機画像を参照して制作した各4コマの初稿があります。推奨枚数と最終品質の確認は残っています。設計図の小さなポーズ例を切り抜いた画像ではありません。

画像を追加した動作は、親フォルダの `character.json` のファイル一覧・FPS・`available` を確認してから有効化します。画像の作成規格は `../../../../docs/SPRITE_ASSET_SPEC.md` を参照してください。
